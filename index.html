成都地铁个人行程数据获取指南

本教程用于指导您如何导出个人乘车记录，并生成可直接导入本可视化项目的 CSV 文件。

一、APP 端导出行程 PDF

⚠️ 重要提醒：申请报销（开发票）仅有一次机会！如果您有报销需求，务必正确填写接收邮箱，并确认需要的报销格式（电子发票/纸质发票）。强烈建议不要在 AI 免费转换环节浪费这次机会——请先用少量行程测试 CSV 生成效果，确认无误后，再用真实完整数据正式走报销流程。
  1. 打开 成都地铁 APP，进入底部【我的】页面
  2. 点击【我的行程】，查看全部乘车记录
  3. 页面右上角选择【开发票】功能
  4. 点击左下角 全选行程
  5. 填写个人接收邮箱，提交申请
  6. 登录邮箱，下载收到的行程 PDF 文件

二、AI 转换为标准 CSV

  1. 将下载好的行程 PDF 上传至您常用的 AI 助手（如 ChatGPT、Kimi 等）
  2. 复制下方提示词发送，等待数据解析转换：
请解析这份地铁行程PDF文件，严格按照`序号,出发站,到达站,日期`的逗号分隔格式整理数据，输出标准CSV文本内容。 如果遇到 -- 或 00 等无意义符号，说明是有轨电车数据，请将出发和到达站均统计为“有轨电车”。 格式示例： 序号,出发站,到达站,时间 1,犀浦,洪河,2025.06.07 2,建设北路,春熙路,2025.06.19 整理完成后直接生成可下载的CSV文件。站点名称原样保留，日期统一保留年月日格式即可。
  1. 下载 AI 生成的 CSV 文件

三、使用说明

获取 CSV 文件后，切换至本页面的 [导入数据] 板块，选择文件即可瞬间生成您的个人专属乘车足迹图表与排行分析。

四、数据异常处理（控制台警告）

导入 CSV 后，如果发现某些站点未显示在地图上，或统计数量与预期不符，请按以下步骤排查：

  1. 在页面中按 F12 或 Ctrl+Shift+I 打开浏览器开发者工具
  2. 切换到 Console（控制台） 面板
  3. 查看是否存在形如 【警告】以下 CSV 行程中的站点无法在底图中匹配... 的黄色警告输出
  4. 警告中会列出所有未能匹配的站点名称 —— 这些站点的数据已被自动跳过，因此未计入统计

根本原因是 CSV 中的站点名称与底图数据中的名称存在差异（如多字、少字、错别字等），需要通过配置别名映射来解决。

五、修复站点匹配问题（配置 stationAliasMap）

本项目提供了 stationAliasMap 别名映射机制，可将 CSV 中的名称重定向到底图中正确的站名：

  1. 用文本编辑器打开本页面 index.html（如果是本地版则打开 final_map.html）
  2. 搜索 stationAliasMap 找到别名配置区域（约在第 413 行）
  3. 按照现有格式添加映射条目：
    "CSV 中的原始站名": "底图中的标准站名"
  4. 保存文件，刷新页面，重新导入 CSV 即可生效
// stationAliasMap 配置示例 // 格式： "CSV里的写法": "地图里的标准名称" "火车北站": "火车北站", // 别名与原值一致，强制参与匹配 "春熙路站": "春熙路", // CSV 多了一个"站"字，映射到无"站"的底图名称 "天府广场站": "天府广场", // 同上 "界碑": "界牌" // CSV 写了错别字，纠正到正确站名
⚠️ 每次修改 stationAliasMap 后，必须刷新页面并重新导入 CSV 才能生效。建议先用少量数据测试确认匹配无误，再处理完整数据集。
