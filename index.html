成都地铁综合看板使用教程

从行程单到足迹与习惯分析：一次导入，在地图看板、时间分析、探索洞察、花费分析之间切换。个人文件只在浏览器内存处理，刷新页面后需要重新导入。

一、准备行程单

  1. 在成都地铁 App 的“我的 → 我的行程”中，按 App 当前提供的流程导出所需行程单。
  2. 如果通过“开发票”接收行程单，请核对邮箱和所选行程，并按实际报销要求操作。
  3. 从收到的邮件中下载原始 PDF；无需先转换成 CSV，也无需截图。

二、导入 PDF 或 CSV

  1. 点击顶部“导入数据”。PDF 点击“选择 PDF 行程单”；CSV 点击“选择 CSV 文件”。可以多选同类型文件，每次选择替换之前的数据。
  2. PDF 支持成都地铁文字型行程单，自动处理分页、重复文字、特殊汉字和有轨电车。每个账单的数量与金额核对通过后，才更新看板。加密 PDF 请先解锁；扫描件目前不支持识别。
  3. CSV 需要“出发站、到达站、时间”表头，UTF-8 编码；时间需包含年月日和小时分钟，可保留秒。
  4. 解析成功后自动进入地图。多份文件按站点和完整交易时间去重，重复行开关可在分析页调整。

三、地图看板

查看站点足迹和频次排行，切换“全网地图 / 频次排行”。顶部摘要显示当前筛选行程数、涉及站点和未匹配站点数。出发与到达各增加一次站点频次；一笔有轨电车计一笔行程、两次站点频次。

四、时间分析

  1. 设置起止日期、每天的开始 / 结束时刻、站点关键词、星期范围和重复行开关，修改后点击“确认筛选”才生效；未修改时按钮灰色。已确认的筛选同时作用于地图和探索洞察。点击“重置筛选”恢复完整范围。
  2. 切换年、季度、月、ISO 周或日，查看趋势、环比、小时分布、星期热力图、活跃日历和累计行程。图表下方滑块可缩放时间范围。
  3. 每天时刻精确到分钟，开始包含、结束不包含，支持跨午夜，留空表示不限，起止相同表示空区间。调整早晚高峰开始与结束小时也需点击确认。开始包含、结束不包含，支持跨午夜，重叠部分不重复计数。
  4. 日均包含没有行程的日期；活跃日均只统计有行程天数。周一至周五不是法定工作日口径，未处理节假日和调休。

五、探索洞察

查看站点首次出现进度、常用路线集中度、各年月份对比、月度画像、双向路线、站点常见小时与高频日期提示。所有结论来自当前筛选记录：首次出现不等于真实首次到访，双向路线不等于同日往返，相邻交易间隔不等于乘车时长。

六、花费分析

点击顶部“花费分析”，查看已知总花费、单次平均与中位费用、分期花费、费用分布、累计花费、高峰 / 周末对比，以及出发站、到达站和路线花费排行。PDF 自动读取金额；CSV 可添加“金额”或“金额(元)”列，单位为元，支持最多两位小数。

旧版 CSV 没有金额时，打开本页会提示，但其他分析照常使用。部分缺失或不合法的金额不按 0 元计算，页面显示金额覆盖率；实际 0 元记录保留。同一行程金额冲突时不计入花费，控制台列出原因。出发站、到达站花费分别归组，不可相加；有轨电车每笔费用只汇总一次。花费页同样遵循确认后的筛选。

七、导出与本地使用

时间分析和探索洞察底部可“导出统计 CSV”“导出筛选行程 CSV”，也可打印或保存 PDF。导出的行程保留秒级时间和金额列，无金额记录留空；统计导出也包含花费指标。Windows 双击 start_dashboards.bat 启动本地服务器并打开综合看板；保持窗口运行，关闭或 Ctrl+C 停止。

八、解析失败与诊断

  1. 失败时页面显示简短原因，原有数据保留，不导入未核对成功的部分结果。
  2. 按 F12 或 Ctrl+Shift+I，进入 Console，查找“[行程导入]”日志。PDF 诊断包括文件名、页码、各页提取数量、每个账单的预期与实际笔数和金额、未识别行及错误堆栈。
  3. “没有可提取文字”通常意味着扫描件；“数量或金额核对不一致”可能是模板变化或漏行；“组件加载失败”请刷新并检查浏览器 Network 面板。
  4. 未匹配地图的站点只缺少地图显示，行程仍参加时间和探索统计。可在 index.html 中搜索 stationAliasMap 添加精确别名，刷新后重新导入。
