# 成都地铁行程导入与综合分析指南

1. 在成都地铁 App 的“我的 → 我的行程”中按当前 App 流程导出行程单。如果通过开发票流程接收文件，请核对所选行程和邮箱，按实际报销要求操作。
2. 开发票邮件可能包含发票 PDF、XML、OFD 等多个附件；下载其中的“行程单.pdf”即可。然后打开网站的“导入数据”，点击“选择 PDF 行程单”，可一次选择多份。无需先截图或转换 CSV。
3. 网页在浏览器本地提取文字并核对每份账单笔数、金额。全部成功后进入地图；失败时显示简短原因，F12 → Console 的 `[行程导入]` 日志可诊断，旧数据保留。
4. 支持成都地铁文字型行程单，扫描件和加密文件暂不支持；加密文件需先解锁。
5. 也可选择 CSV。所需表头为 `出发站,到达站,时间`；时间包含年月日、小时和分钟，可保留秒。可选金额列为 `金额` 或 `金额(元)`，单位元，最多两位小数。
6. 一次导入后，顶部切换地图看板、时间分析、探索洞察、花费分析。旧版 CSV 缺少金额时，花费页会提示，其他分析正常使用。
7. 在分析页修改日期、每天的几点几分、站点、星期或高峰参数后，点击“确认筛选”才同步生效；未改动时按钮灰色。每天开始包含、结束不包含，支持跨午夜，留空表示不限。重置立即恢复完整范围。
8. 花费分析只汇总已知合法金额，缺失值不当成 0 元；每笔有轨电车只计一笔费用。地图的出发、到达端点各计一次站点频次。
9. 分析页底部可导出统计 CSV、带金额的筛选行程 CSV，也可打印 / 保存 PDF。个人文件不上传，刷新后需重新导入。
10. 本地使用时双击 `start_dashboards.bat`；也可在目录运行 `python -m http.server 8000 --bind 127.0.0.1`，访问 `http://127.0.0.1:8000/index.html`。
