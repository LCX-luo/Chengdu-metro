# 网站访问与功能使用统计

网站已预留 Umami 接入。`网站资源/脚本/访问统计配置.js` 中的 `websiteId` 为空时不加载统计服务，尚未开始收集访问数据。

## 账号与启用

1. 在 https://cloud.umami.is/signup 注册并验证邮箱。选择满足需求的方案；官方目前提供免费 Hobby 方案，具体额度和保留时间以 https://umami.is/pricing 为准。
2. 创建网站，名称可填“成都地铁行程分析”，域名填写 `lcx-luo.github.io`。实际入口是 https://lcx-luo.github.io/Chengdu-metro/ 。
3. 在网站设置中复制 Tracking code。将其中的公开 `data-website-id` 和 `src` 分别填入配置的 `websiteId` 和 `scriptUrl`，或将整段跟踪代码交给维护者完成配置。不要提供账号密码、API 密钥；不必在 HTML 中额外插入另一段跟踪代码。
4. 提交并推送 GitHub，等待 Pages 发布。访问线上入口，在 Umami 控制台的实时数据和事件中核对结果。本地地址不会上报，嵌入分析页不会重复计算浏览量。

## 查看使用人数

在 Umami 控制台选择本网站和统计时间范围，查看 Visitors（估算独立访客）、Views（浏览量）以及 Events（操作事件）。独立访客不等于精确真实人数，不提供真实身份或跨设备永久身份编号。只能统计启用后的访问，无法补录以前的使用人数。

事件名称：

| 事件 | 含义 |
| --- | --- |
| `view-dashboard` / `view-import` / `view-help` | 切换地图、导入、教程 |
| `view-time` / `view-explore` / `view-costs` | 切换时间、探索、花费分析 |
| `import-csv-success` / `import-pdf-success` | 成功导入个人文件 |
| `load-demo-success` | 成功加载示例 |
| `confirm-filters` | 确认有效筛选 |
| `export-statistics` / `export-trips` | 导出统计或筛选行程 |
| `print-report` | 打开打印界面（不代表实际打印完成） |

事件次数会包含同一访客重复操作，不能直接当成人数。成功导入事件更适合衡量实际使用情况；可在服务支持的事件筛选或目标中查看对应访客。

## 隐私与排查

只发送固定操作名称和基本页面元数据。上报前删除自定义数据，页面地址仅保留路径，来源仅保留域名；不发送文件名、站点、乘车时间、金额、筛选值、解析异常或任何行程内容。不启用回放、热图或永久访客 ID。

用户可以在使用教程或分析页底部关闭当前浏览器统计；同时尊重 Do Not Track 和 Global Privacy Control。站长可在自己的浏览器勾选关闭，排除个人使用。统计受浏览器隐私设置、广告拦截器和网络状况影响，不能保证每次打开都被记录。统计服务不可用时不会阻止导入、地图或分析。

若没有数据，先核对网站 ID 和脚本地址、Pages 发布版本，再检查 F12 → Network 中统计脚本及请求。跟踪实现参考 [Umami 收集数据](https://docs.umami.is/docs/collect-data)、[配置](https://docs.umami.is/docs/tracker-configuration) 和 [事件 API](https://docs.umami.is/docs/tracker-functions)。
